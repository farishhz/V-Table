## About

OG Table is a simple tool that helps you design **beautiful, presentation-ready tables**.

Pick a theme, choose a background, and start filling in your data.  
No design skills required — just clean visuals that actually match your slides.

## ✨ What It Does

OG Table lets you:

- Choose from clean, modern table themes
- Customize backgrounds, borders, and corner radius
- Adjust spacing and layout to fit your slide aesthetic
- Export tables as images
- Control export resolution for crisp results on any screen

When you’re happy with the result, just hit **export** and drop the image straight into your deck.

## 🌱 Why I Built This

I was working on a slide deck.

Everything looked great — modern font, subtle gradient background, nice spacing.  
Then I added a table.

Instant disaster.

Gray borders.  
Clunky cells.  
Zero vibe.

It looked like it came straight out of a 2003 Excel sheet.

That’s when I realized:

**tables deserve better.**

So I built **OG Table** — a tool for people who care about design but still need tables that communicate clearly.

The goal was simple:

- Clean by default
- Highly customizable
- Export-ready
- Easy to use

No more sad tables ruining beautiful slides.

## 🧱 Tech Stack

OG Table is built with a modern frontend-focused stack:

- **Framework**: Next.js
- **UI & Components**: Radix UI + Tailwind
- **State Management**: Jotai
- **Animations**: Framer Motion
- **Image Export**: html-to-image
- **Icons**: Lucide, Raycast Icons

The stack is optimized for interactivity, performance, and a smooth design experience — even for complex table editing.
